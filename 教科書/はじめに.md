# 福島のごはん屋さんくじ　教科書

## この教科書の進め方
1. 完成品は `gohan-kuji/` に**もうあります**（＝答え）。まず遊んでみよう。
2. 次に、空っぽの `gohan-kuji/practice/` フォルダに**自分の手で**1ステップずつ作り直します。
3. わからなくなったら、Claude に「**先生、レッスン○を教えて**」と話しかけてください。
   先生（sensei）が例え話・確認クイズ・ちょい変え課題つきで教えてくれます。
4. 終わったレッスンは `進捗.md` に先生が記録します。

> 💡 先生は答えをすぐには教えません。「ヒント → 一部の答え → 完成品のどこを見ればいいか」の順に出します。

## アプリの全体像（ファイルの役割）

| ファイル | 役割 | 例えると |
|---|---|---|
| `index.html` | 画面に何を置くか | お店の**間取り図** |
| `style.css` | 色・大きさ・並べ方 | **内装・インテリア** |
| `app.js` | ボタンを押したら何をするか | **店員さんの動き** |
| `config.js` | 町やジャンルの決まり | **お店のルール表** |
| `shops.js` | 郡山のお店リスト（自動で作られる） | **お店の名簿** |
| `tools/update_shops.py` | お店リストを集めるプログラム | **名簿を作る係の人** |

## レッスン0：完成品で遊ぶ
① `gohan-kuji/start.bat` をダブルクリック（ブラウザでアプリが開く）
② 「飲み屋」を押して → 「くじを引く」
③ 「チェーン店を除く」のチェックを外すと、候補の軒数が増えることを確かめる

🧠 **考えてみよう**：アプリはどこから郡山のお店を知ったのでしょう？
（答えは `shops.js` の1〜2行目に書いてあります）

## お店データについて
- お店は **OpenStreetMap**（みんなで作る無料の地図）から集めています。登録・APIキー・お金は不要です。
- ★の評価は入っていません。当たったお店の「Googleマップ」ボタンで★を確認できます。
- 新しいお店を取り込みたいときは `tools/update_shops.bat` をダブルクリック（1〜3分）。
- OpenStreetMap に載っていないお店は出てきません（カレー・スイーツは少なめ）。
