# MeMap（写真の撮影場所マップ）

「ユニバで撮った」ではなく、**「ユニバのどこで撮ったか」** までピンで残すためのアプリ（スマホ向け Web アプリ / PWA）。

## できること

| 機能 | 内容 |
|---|---|
| 写真の位置を自動で読む | 写真に入っている GPS 情報（EXIF）から撮影場所・日時・**カメラの向き**・**GPS の誤差**を読み取る |
| その場で撮影 | 「いま撮影する」はカメラを開いている間に GPS を温めておき、いちばん精度のよい位置を記録 |
| **ピンの微調整（いちばん大事）** | 航空写真をアトラクションや建物の入口が見えるくらいまで拡大し（最大ズーム 21）、画面中央のピンに合わせて地図を動かす。元の GPS 位置・誤差の円・撮影方向の扇形が薄く表示されるので、「この橋の上から南東向きに撮った」まで合わせられる |
| スポット検索 | 「ホグワーツ城」などで検索（いま見ている地図の近くを優先） |
| 名前を調べる | ピンの場所のアトラクション名・建物名を自動で入れる |
| 地図 / アルバム | 写真のサムネイルがピンになった地図、タグで絞り込めるアルバム |
| 詳細 | 写真・メモ・座標・撮影方向、Google マップで開く |

写真は **スマホの中（ブラウザの IndexedDB）にだけ** 保存され、サーバーには送られない。

## 動かし方

- パソコン: `start.bat` をダブルクリック → http://localhost:8001
- スマホ: GitHub Pages などの **https** のURLで開き、「ホーム画面に追加」（GPS は https でないと使えない）

## 注意

- iPhone で「写真を選ぶ」ときは、写真選択画面の「オプション」で **位置情報** をオンにしないと GPS が消されることがある
- 地図・検索にはネット接続が必要（OpenStreetMap / Esri / 国土地理院 / Nominatim）
- アプリを消したりブラウザのデータを消すと写真も消える

## ファイル

- `index.html` 画面 / `style.css` 見た目 / `app.js` 本体
- `lib/` 地図の部品 [Leaflet](https://leafletjs.com/) と、写真の位置情報を読む部品 [exifr](https://github.com/MikeKovarik/exifr)（どちらも MIT）
